# ملف المراجعة المسبق (AuditPrep)

برنامج ويندوز لتجهيز متطلبات المراجع الخارجي قبل بدء المراجعة: ميزان المراجعة والمقارنة والتنبيهات، إعادة تبويب
الأرصدة المعاكسة، تبويب الحسابات على بنود القوائم، التسويات، القوائم المالية والإيضاحات، فحوصات المطابقة،
الأصول الثابتة وفواتير الإضافات، السياسات المحاسبية، طلبات المراجع ومرفقاتها، المستندات الرسمية، والخطابات والتفويضات.

## التحميل والتثبيت

1. افتح صفحة **Releases** في الـ repo ونزّل `AuditPrep-Setup-x.y.z.exe` (أو النسخة Portable).
2. شغّل الملف. لأن البرنامج غير موقّع رقميًا، ويندوز ممكن يظهر رسالة "Windows protected your PC": اضغط
   **More info** ثم **Run anyway**.

## مكان حفظ البيانات

كل البيانات والمرفقات بتتحفظ في فولدر على الجهاز (الافتراضي `Documents\AuditPrep`):
- `db\` ملفات JSON لكل طلب ومستند وإعداد والميزان.
- `files\` المرفقات (PDF، صور، إكسيل…) بأسمائها الداخلية.

من **الإعدادات** تقدر تغيّر الفولدر (مثلًا فولدر جوه OneDrive عشان نسخة احتياطية أونلاين تلقائية)، وتفتحه،
وتحمّل أو تستورد **نسخة احتياطية كاملة** (ملف zip واحد). نفس النسخة الاحتياطية بتنقل الشغل من النسخة الأونلاين للبرنامج.

## للمطورين

```
npm install
npm start          # تشغيل البرنامج
npm test           # اختبارات طبقة التخزين
npm run dist       # بناء ملفات ويندوز في dist/
```

- `src/audit-prep.html` هي واجهة البرنامج كاملة (نفس صفحة النسخة الأونلاين).
- `src/local-claude.js` بيوفر للصفحة الحفظ والمرفقات والتحميل من الجهاز بدل السحابة.
- `main.js` و `preload.js` و `storage.js` هي غلاف Electron.
- `scripts/build-app.js` يجهز فولدر `app/` (المكتبات محليًا بدل الإنترنت).

كل push على `main` يبني البرنامج على GitHub Actions وينشر الإصدار في Releases باسم رقم الإصدار في `package.json`،
فلازم تزود الرقم مع كل إصدار جديد.
